# PerumBca

Sistem Informasi Iuran Perumahan Bumi Cikarang Asri — tagihan iuran, tunggakan (FIFO), pembayaran tunai/transfer/Midtrans, buku kas, persetujuan pengeluaran, laporan, dan notifikasi WhatsApp.

Stack: Node.js + Express, PostgreSQL + Prisma, Bootstrap 5 (server-rendered), Midtrans Snap, Baileys, Docker + Traefik di Armbian.
